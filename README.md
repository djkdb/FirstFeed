# 퍼스트피드 (FirstFeed)

인스타그램을 처음 시작하는 사람이 **정체성 찾기 → 브랜딩 → 템플릿 고정 → 카드뉴스 만들기 → 업로드 준비**를 한 곳에서 하는 **로컬 앱**입니다. 자기 컴퓨터에서 웹 화면 + 로컬 서버로 돌고, AI 는 사용자 본인의 Claude 구독(Claude Code CLI)으로 부릅니다.

CUVIC 바이브 코딩 대회(개인전) 출품작입니다.

- **지금 상태: 1차 개발 중** — 기준 문서는 [PRD v0.2](docs/PRD.md)(우선순위 M·F·S·W). 요구사항별 진행은 [docs/process/status.md](docs/process/status.md)
- 이전에 만든 개인 자동화 프로그램(카드뉴스공장, insta_auto)의 코드·프롬프트는 쓰지 않았습니다(대회 규칙).
- 지인 인터뷰·대외활동 공지 같은 비공개 자료는 레포에 넣지 않습니다(`tests/fixtures/private/` 는 커밋 제외, 파일 목록·건수만 공개).

## 필요한 것

| 무엇 | 비고 |
|---|---|
| macOS | 지금은 macOS 에서만 써 봤습니다. Windows 는 최종 발표까지 확인 목표(확인 필요) |
| Node.js 24 이상 | `package.json` 의 `engines`. 설치 방법은 이 레포에 정리돼 있지 않습니다(확인 필요) |
| Claude Code CLI 설치와 로그인 | 설치는 앱 안내 그대로: 「https://claude.com/claude-code 의 안내대로 설치」. 로그인도 앱 안내 그대로: 「터미널에서 `claude` 를 실행해 로그인한 뒤 [다시 확인]을 누르세요」 |
| Claude 유료 구독 | 앱은 AI 를 부르기 직전에 `claude auth status` 로 구독 로그인인지 확인하고, 구독이 아니면(API 키 등) 호출하지 않습니다 |

## 설치와 실행

`package.json` 과 [CLAUDE.md](CLAUDE.md) 4장에 있는 명령만 적었습니다.

```sh
git clone https://github.com/djkdb/FirstFeed.git
cd FirstFeed
npm install                        # 의존성 설치 (git 저장소면 커밋 전 검사 훅도 같이 켜짐)
npx playwright install chromium    # 카드 이미지를 그릴 브라우저 — 처음 한 번
npm run dev                        # 서버 127.0.0.1:4317 + 화면 5173
```

브라우저에서 **http://localhost:5173** 을 엽니다. 「점검」 탭에서 Claude Code 연결 상태(설치 · 로그인 · 구독)를 볼 수 있습니다.

- 앱은 브라우저를 직접 내려받지 않습니다. Playwright Chromium 이 없으면 설치된 Google Chrome 으로 그리되 「기준 브라우저 아님」을 표시하고, 둘 다 없으면 설치 명령을 안내합니다(결정 2026-10-15)
- 업로드 폴더는 기본으로 `~/Downloads/FirstFeed/` 에 만들어집니다(화면에서 바꿀 수 있음)
- 더블클릭 실행 · 설치 점검 명령(FR-AC-6)은 아직 없습니다

### 검사 명령 (개발용)

| 하는 일 | 명령 |
|---|---|
| 린트 · 타입 체크 · 테스트 한 번에 | `npm run check` |
| 공개 레포 개인정보 검사 | `npm run check:privacy` |

AI 를 실제로 부르는 측정 명령(구독 사용량이 듦)은 [CLAUDE.md](CLAUDE.md) 4장에 있습니다.

## 처음 설치부터 첫 카드뉴스까지 — 단계 수

> 위험 감시 지표용. 세는 기준: **명령 하나, 또는 화면에서 누르는 것(고르기·버튼) 하나 = 1단계.** 글 입력은 그 글을 보내는 버튼에 포함하고, AI 를 기다리는 시간은 세지 않는다. 가장 짧은 길(선택 문항·선택 기능은 건너뜀, 재작성·실패 없음) 기준. 화면 코드(`app/src/`)를 읽고 센 것이고, **처음부터 끝까지 실제로 따라 하며 세지는 않았다(확인 필요)** — 2026-10-21

| 구간 | 단계 | 수 |
|---|---|---|
| 설치 | Node 24 설치 · Claude Code 설치 · `claude` 로그인 · `git clone` · `npm install` · `npx playwright install chromium` · `npm run dev` · 브라우저에서 열기 | 8 |
| 정체성 | 설문 필수 6문항 고르기(8문항 중 2개는 선택) · 「인터뷰 시작」 · 인터뷰 답 보내기 3~10번 · 「이제 프로필 만들기」 · 「이 프로필로 확정」 | 12~19 |
| 브랜드 | 「시각 후보 만들기」 · 색 팔레트 고르기 · 폰트 짝 고르기 (템플릿에 필요한 것만 — 아이디·이름·바이오는 카드에 필요 없음) | 3 |
| 템플릿 | 「이 틀로 고정」 | 1 |
| 만들기 | 소재 붙여 넣고 「표지 제목 후보 만들기」 · 표지 하나 누르기(본문까지 만들어짐) | 2 |
| **합계** | | **26~33** |

- 인터뷰 질문 수(3~10개)가 매번 달라 범위로 적었다. 업로드 폴더까지 가면 「업로드 폴더 만들기」 등이 더 붙고, 소재 밖 풀이 문장이 표시되면 그 수만큼 「확인했어요」가 더 붙는다
