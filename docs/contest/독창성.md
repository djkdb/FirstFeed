# 독창성 — 차별점 4개와 실제 기록

> 2026-10-21 작성. 공지 세부 기준: 「제안하는 해결 방안이 기존 서비스와 차별화되는 고유한 가치를 지니고 있는가」(중간 30%).
> 각 차별점에 **레포에 남은 실제 기록**(devlog · `tests/results/` · 파일 · 커밋)을 붙였다. 측정 갈래(실제·공개 / AI 생성)를 같이 적는다 — 실제·공개는 `tests/fixtures/real/`(운영자 본인), AI 생성은 `tests/fixtures/generated/`(`tests/fixtures/README.md`).
> **경쟁 서비스 비교 칸은 비워 둔다** — 기존 서비스의 최신 기능을 레포에서 확인할 수 없어서. 발표 전 사용자가 최신 기능을 확인해 채운다.

## ① 근거 없는 숫자·이름은 코드가 잡아 다시 쓰게 하고, 확인할 수 없는 풀이는 사람에게 보인다

- **장치**: 콘텐츠 속 숫자·버전·날짜·영문 이름이 허용 출처 4가지(소재 원문 · 브랜드 프로필·키트 · 구조에서 나온 숫자 · 사용자가 직접 쓴 문장)에 없으면 재작성(`server/src/rules/grounding.ts`, CLAUDE.md 5장). 재작성 2회로도 안 되면 저장하지 않는다(`server/src/ai/loop.ts`)
- **기록 — 규칙이 실제로 잡은 것**(AI 생성 소재 「온실 베이커리」):
  - 표지 후보 「평일 0분 주말 **40분**」 → `[number_not_in_source] 소재·프로필·메모에 없는 숫자 "0"` 으로 빠짐(`tests/results/2026-10-15-cards-body-v1.md` 151줄). 같은 모양이 다른 회차에도: `2026-10-15-cards.md` 135줄 · `2026-10-20-cards-gen-v3.md` 214줄
  - 표지 후보 부제 「평일 3시 **vs** 주말 1시」 → `[english_not_in_source] … 영문 이름 "vs"` 로 빠짐(`tests/results/2026-10-15-cards-body-v2.md` 155줄)
  - 최종 카드의 원문 밖 숫자·영문: **0**(devlog 2026-10-15-02 39줄 · 2026-10-18-01 38줄 · 2026-10-18-03 59줄)
- **한계도 같이 적는다**: 숫자는 원문 어딘가에 있는지만 보고, 한글 고유명사는 검사하지 않는다(CLAUDE.md 5장 「알려진 한계」) — 그 빈틈은 자기 평가가 맡는다
- **용어 풀이 표시**: 입문자용 카드엔 풀이가 필요하지만 맞는지 코드로 잴 수 없다 → 소재에 나온 용어의 풀이만 허용하고 표시, **사람이 확인하기 전엔 업로드 폴더를 만들 수 없다**(결정 2026-10-15 · 2026-10-18, `server/src/cards/gloss-check.ts`)
  - 기록: card_body v2 에서 소재 밖 용어 풀이 4개가 나왔고 **4/4 표시**(AI 생성 소재 3개 × 2회, `tests/results/2026-10-15-cards-gloss-v1-v2.md`, devlog 2026-10-15-04 40~41줄)
  - 리허설에서 사람이 표시된 설명 문구를 원문과 대조해 확인 표시(devlog 2026-10-21-02)
- **재작성 「전/후」 문장이 같이 남은 기록은 없다** — 결과 파일은 빠진 후보와 이유, 최종 결과만 남긴다. 전후를 그림으로 보이려면 화면 캡처가 필요하다([중간보고서-초안.md](중간보고서-초안.md) 그림 1)

## ③ 프로필을 바꾸면 이후 생성에 반영된다 (FR-ID-6)

- **장치**: 사용자가 고른 판은 바로 활성, 다음 생성의 축·말투·피할 것에 반영(결정 2026-10-14, PRD v0.2 FR-ID-6)
- **기록**(`tests/results/2026-10-14-brand-reflect-me.md`, me = 실제·공개, 각 1회, devlog 2026-10-14-03 52줄, 측정 커밋 `3b2f7f0`):

  - 전: 「새로 나온 AI·개발 도구, 공식 문서 보고 직접 써 본 것만 정리해**요** ⏎ 🔧 써 본 도구 · 🤖 AI로 만든 것 · 📝 **대외활동 기록** …」
  - 후: 「새로 나온 AI 도구, 직접 써 보고 바로 쓰게 정리**해** ⏎ 🛠 써 본 새 도구 · 🧩 AI로 만든 것 · 🧯 **실패 기록** …」

## ④ 정체성의 축마다 사용자가 한 말이 인용으로 붙는다

- **장치**: 축마다 설문·인터뷰 답의 인용을 붙이고, 공백·문장부호를 정리한 뒤 **원문의 부분 문자열인지 코드가 확인한 인용만 저장**한다. 근거가 없는 축은 빼고, 3개 미만이면 인터뷰로 돌아가 더 묻는다(FR-ID-4, `fd7e1d9`). AI 가 써 준 예시 답을 그대로 보낸 답은 근거가 아니다(`example_only_evidence`)
- **기록**(`tests/results/2026-10-14-identity-profile-v2.md` 33~55줄, me 1회 = 실제·공개):
  - 축 「직접 써 본 새 도구」 ← 「남이 정리한 걸 옮기지 않고, 발표 원문이나 공식 문서를 직접 보고 써 본 것만 쓴다.」(인터뷰 3번 답)
  - 축 「활동 기록」 ← 「그 계정 덕분에 네이버 AI 디깅클럽과 행정안전부 주관 청년 공공 AX 서포터즈에 선정됐다.」(인터뷰 2번 답)
  - 같은 파일 측정: 무효 인용(모든 시도 합) **0**(17줄) · 근거 부족해 인터뷰로 돌아간 경우도 기록(59~60줄 「직접 한 말에서 근거를 찾을 수 있는 축이 3개가 되지 않았습니다」)
