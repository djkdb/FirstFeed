### 꺼내는 법

```sh
npm run export:transcripts -- 6887510c-f5b2-49b7-a2cf-d074e050fe51   # devlog 에 적힌 세션
npm run export:transcripts -- --all                                   # 이 프로젝트 폴더의 모든 세션
```

- 결과: `exports/<세션ID>.md` — `.gitignore` 로 막혀 레포에 올라가지 않는다(`scripts/export-transcripts.ts` 머리 주석)
- 기본은 도구 결과를 뺀다. 넣으려면 `--with-tool-results` (파일 내용이 그대로 들어가 길고, 비공개 자료를 읽은 결과가 섞일 수 있다)
- 가림: `server/src/lib/redact.ts` 의 규칙 6가지 — 개인 키 · API 키·토큰 · JWT · 비밀 값 · 이메일 · 전화번호. 커밋 전 개인정보 검사와 같은 함수다(결정 2026-10-13)
- ☐ **가리지 않는 것**: 사람 이름, 지인 인터뷰·대외활동 공지의 내용. 대화 중 비공개 자료(`tests/fixtures/private/`)를 다룬 부분이 있으면 내보낸 파일에 남는다 — 제출 전에 내보낸 파일을 읽어 확인 **(사용자)**
- ☐ 내보낸 뒤 출력 줄의 「가림」 건수를 확인하고, 파일을 열어 가림 표시가 엉뚱한 곳(코드 예시 등)에 붙지 않았는지 본다 **(사용자)**

### 이 스크립트로 안 나오는 것

- ☐ **Claude 앱(claude.ai)에서 한 기획 대화**(PRD v0.1 질의응답 이전 기획, 매니패스트 채팅의 1·2단계 답변 — PRD v0.2 「자료 1~4」 아래 메모)는 이 스크립트로 나오지 않는다. 스크립트는 `~/.claude/projects/<이 레포 경로>/` 의 Claude Code 대화만 읽는다. **제출 범위에 들어가는지 공지 확인 필요(사용자)**. 들어간다면 각 서비스의 공유·내보내기 기능으로 따로 꺼낸다
