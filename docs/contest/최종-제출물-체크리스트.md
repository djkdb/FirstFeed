### 2-2. AI 대화 기록 내보내기

`npm run export:transcripts` 는 **이 컴퓨터의 `~/.claude/projects/<레포 경로의 / 와 . 을 - 로 바꾼 이름>/` 에 있는 Claude Code 대화만** 읽는다(`scripts/export-transcripts.ts` 15줄 — 2026-11-20 읽어 확인). 그래서 대화가 어디서 돌았는지에 따라 꺼내는 곳이 다르다.

devlog 첫 표 「세션 ID」 칸에 이미 적힌 세션(2026-11-20 셈, devlog 46편):

| 세션 ID | 어디서 | devlog |
|---|---|---|
| `6887510c-f5b2-49b7-a2cf-d074e050fe51` | 사용자 맥의 Claude Code | 2026-10-13-01 ~ 2026-10-30-01 (32편) |
| `session_01Uqv9AyJRqyY2gMhXEUkCkD` | 클라우드 원격 세션(claude.ai/code) | 2026-11-04-01 · 2026-11-05-01 |
| `ee2a416f-10fb-5024-8dd8-bb41006c6d43` | 클라우드 세션 — devlog 2026-11-05-02 에 「11-04 부터 이어짐」 | 2026-11-05-02 ~ 2026-11-20-03 (12편) |

- **사용자 맥에서 돈 세션**: 그 맥에서 `npm run export:transcripts -- 6887510c-f5b2-49b7-a2cf-d074e050fe51` → `exports/<세션ID>.md`(`.gitignore`). 그 맥의 레포 경로가 대화 때와 같아야 찾는다(폴더 이름을 경로에서 만든다)
- **클라우드 세션은 사용자 맥의 `~/.claude/projects` 에 없다** — 대화 파일은 그 세션의 클라우드 컨테이너 안에 있다. 따로 꺼내야 한다:
  - ☐ 세션이 살아 있는 동안 **그 컨테이너 안에서** 같은 명령을 돌린다(2026-11-20 이 컨테이너의 `~/.claude/projects/-home-user-FirstFeed/` 에는 `ee2a416f-…` 대화 파일 하나만 있고 폴더는 11-04 에 생겼다 — 그래서 `session_01Uqv…` 와 `ee2a416f-…` 는 같은 클라우드 세션의 두 이름(claude.ai 세션 주소 · CLI 대화 파일)으로 보인다. **짐작, 확인 못 함**). 이 컨테이너 대화 파일은 약 165MB 라 내보낸 파일도 길다
  - ☐ 컨테이너가 바뀌어도 대화 파일이 남는지, claude.ai/code 에서 대화를 내보내는 기능이 있는지 — **확인 못 함 (사용자)**
- **Claude 앱(claude.ai) 기획 대화 · 매니패스트 채팅**은 이 스크립트로 안 나온다(중간 체크리스트 3장과 같음) — 각 서비스의 공유 · 내보내기로 **(사용자)**
- 가림: `server/src/lib/redact.ts` 규칙(개인 키 · API 키 · 토큰 · JWT · 비밀 값 · 이메일 · 전화번호). **사람 이름 · 지인 인터뷰 · 대외활동 공지 내용은 가리지 않는다**
- ☐ 내보낸 파일을 열어 비공개 자료(`tests/fixtures/private/`)를 읽은 부분 · 가림이 엉뚱한 곳에 붙은 곳이 없는지 본다 **(사용자)**
- ☐ 2026-11-20 설정 탭에 토큰 · 키를 넣은 세션이 있다면 대화에 값이 찍히지 않았는지 다시 본다 — 앱은 값을 화면에 끝 네 자리만 보이고 키체인에만 둔다(결정 2026-11-20). 대화 쪽은 내보낸 뒤 확인 **(사용자)**
