## ④ 트러블슈팅 및 위기 극복 — `#트러블슈팅` ~~14편~~ 39편 · CLAUDE.md 「겪은 오류」 ~~20개~~ 27개 (2026-10-21 → 2026-11-20 셈)

대표 사례:
1. **잠자기가 시간에 섞였다 — 그리고 첫 진단도 틀렸다**: 제한 360초 호출이 4172초로 기록. 「opus 가 느리다」로 읽었다가 pmset 로그로 덮개 닫힘·잠자기를 찾았고, 「hrtime 은 잠든 동안 멈춘다」는 가정도 SIGSTOP 실험으로 틀린 것을 확인(CLAUDE.md 「겪은 오류」, devlog 2026-10-14-03 · 2026-10-15-02)
2. **손자 프로세스가 파이프를 쥐고 있어 시간 초과가 늦게 울렸다**: 제한 180초 호출이 703초 뒤에 끝남 → 끝남의 기준을 `close` 에서 `exit` 로(devlog 2026-10-13-04 100~102줄)
3. **셸 인자 하나가 측정 전체를 바꿨다**: zsh 는 따옴표 없는 변수를 쪼개지 않아 옛 판으로 측정 → 인자 읽기를 한 곳으로, 모양이 틀리면 시작 전에 멈춤(devlog 2026-10-18-03 75줄, `scripts/prompt-args.ts`)

2026-10-25 뒤 「겪은 오류」에 올린 후보(2026-11-20 더함 — CLAUDE.md 「겪은 오류」 날짜 그대로):
4. **`scrollIntoView` 가 Promise 를 돌려줘 화면 전체가 깨졌다** — 화살표 함수 효과가 그것을 정리 함수로 돌려줌, 타입 체크 · 린트는 못 잡고 실제 브라우저 콘솔에서 찾음(2026-11-05, devlog 2026-11-05-01)
5. **파일 스트림을 웹 Response 에 그대로 넘겨 서버 전체가 꺼졌다** — 영상 재생기가 요청을 끊자 잡을 수 없는 오류 → `Readable.toWeb`, 끊긴 요청 80번 뒤에도 서버가 사는지 확인(2026-11-06, devlog 2026-11-06-01)
6. **음량을 한 번에 맞추는 loudnorm 이 목표에 못 미쳤다** — −14 목표에 −22.6 → 두 번에(재고 → 같은 만큼 올리기) −14.0, 결과를 다시 재서 화면에(2026-11-06, devlog 2026-11-06-01)
7. **같은 칸 이름 `error` 를 두 뜻으로 썼다** — 요청 실패(문자열)와 작업 실패(객체)가 섞여 티스토리 발행 실패 때 화면 전체가 깨짐, `as` 로 덮여 타입 체크가 못 잡음(2026-11-20, devlog 2026-11-20-01)
8. **「다시 만들어야 하는가」를 판 번호로 판정하거나 판정하지 않았다** — 사용자 시뮬레이션에서 찾음, 그 결과가 쓰는 입력의 내용으로 판정하게 고침(2026-11-09, devlog 2026-11-09-01)
