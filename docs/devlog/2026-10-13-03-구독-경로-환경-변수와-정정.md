## `#측정` 키를 넣으면 claude 는 정말 그것을 먼저 쓰는가
빈 임시 폴더, `--safe-mode --strict-mcp-config --no-session-persistence --tools "" --model sonnet`. 넣은 값은 모두 **가짜**다.

| 환경 | `claude auth status` 의 authMethod | `claude -p` 결과 |
|---|---|---|
| 아무것도 없음 | `claude.ai` (구독 max) | 정상 |
| 가짜 `ANTHROPIC_API_KEY` | **`api_key`** (출처 `ANTHROPIC_API_KEY`, 구독 표시 사라짐) | **401 "Invalid API key"** |
| 가짜 `ANTHROPIC_AUTH_TOKEN` | **`oauth_token`** | **401 "Invalid bearer token"** |
| 닿지 않는 `ANTHROPIC_BASE_URL` (127.0.0.1:9) | — | **60초 동안 응답 없음** (그 주소로 계속 재시도) |

→ 세 변수 모두 **구독 로그인보다 먼저** 쓰인다. 사용자가 다른 개발 작업용으로 셸에 진짜 키를 넣어 두었다면, 고치기 전 앱은 **사용자 모르게 API 요금으로** 돌았을 것이다. 「AI 연결」 화면도 "로그인됨"으로 보였을 것이라(키도 로그인으로 잡힘) 겉으로는 알 수 없었다.
