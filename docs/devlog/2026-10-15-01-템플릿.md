## 오류 → 원인 → 해결

- `#트러블슈팅` **글자 조각(Range 사각형) 높이는 줄 상자가 아니라 폰트 내용 영역이다**
  - 증상: 시안을 세 브랜드로 처음 그렸을 때 12장 중 9장이 "넘침 7~25px", PNG 는 멀쩡(고운바탕이 가장 큼)
  - 원인: line-height 1.06~1.24 제목에서 글꼴 ascent+descent 가 줄 상자보다 커서 위아래로 삐져나옴. scrollHeight 도 그만큼 포함
  - 해결: `fb20c78` — 세로 범위를 (내용 영역 − line-height)/2 만큼 줄여 보고, scrollHeight 도 그만큼은 넘침으로 안 봄. 고운바탕 124px·1.06 테스트
  - CLAUDE.md 「겪은 오류」: 예
- `#트러블슈팅` **tsx(esbuild keepNames)가 함수에 끼우는 `__name` 이 page.evaluate 로 넘긴 함수에서 ReferenceError**
  - 증상: 템플릿 탭이 「그리는 중」에서 멈춤, 서버 로그 `page.evaluate: ReferenceError: __name is not defined`. 테스트(vitest)·node 실행은 통과
  - 해결: `ab90b50` — 페이지에 `__name` 을 먼저 정의. tsx 로 그려 보는 테스트를 더하고, 고치기 전 코드에서 같은 오류로 실패하는 것을 확인
  - 덤: 서버가 일반 텍스트 500 을 주자 화면이 JSON 을 못 읽고 멈춤 — 같은 모양(사라진 작업, 2026-10-14)을 또 겪음. 오류를 보이게 고침
  - CLAUDE.md 「겪은 오류」: 예
- `#트러블슈팅` **브라우저를 띄우는 테스트가 다른 테스트와 같이 돌면 CPU 를 잡아 상관없는 테스트가 5초 제한에 걸린다** — npm test 3번 중 1번, 6개 실패(프로세스·다른 방향 테스트 포함). 해결 `9265372`: vitest 프로젝트 unit / browser, browser 는 파일 병렬 끔. 4번 연속 통과. 그 뒤에도 렌더링 하나가 30초 넘은 일이 1번(따로 8번 돌려 재현 안 됨, 원인 미확인) → 단계별 시간 제한(`7e0a769`)으로 다음엔 어디서 멈췄는지 남게
- `#트러블슈팅` 대체 글꼴 검사가 내 실수를 잡음: B 마무리 카드에 `font-family:'inherit'` — 따옴표 때문에 "inherit" 라는 이름의 폰트가 되어 Apple SD Gothic Neo 로 그려짐. 검사가 PNG 를 안 만들고 이유를 보여서 바로 찾음
- `#트러블슈팅` 측정 스크립트 날짜가 `toISOString`(UTC)이라 한국 새벽에 전날(10-14)로 찍힘 → 이 스크립트는 로컬 날짜로. 다른 측정 스크립트는 그대로(대부분 낮에 돌았음) — 다음에 같이 고칠 것
- `#트러블슈팅` "폰트가 다르면 한 줄 글자 수가 다르다"는 내 가정이 틀림 — 표지 제목 한 줄이 페이퍼로지·고운바탕 모두 10자. 한글은 폭이 1em 에 가깝고 줄은 띄어쓰기에서 바뀐다. 테스트를 실측 기록으로 바꿈
