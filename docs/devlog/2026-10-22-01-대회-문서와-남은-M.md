## 오류 → 원인 → 해결

`#트러블슈팅`
- **날짜를 지시서의 파일 이름에서 가져와 틀리게 적었다** — 문서 23곳에 「2026-10-22 작성」 · 「2026-10-22 공지」라고 적었는데 시스템 시각 · 커밋 시각은 2026-10-21. 공지가 올라온 날짜는 아예 레포에서 확인할 수 없는 값이었다 / 해결: 2026-10-21 로, 공지는 「2026-10-21 받은 공지 — 올라온 날짜는 확인 못 함」으로(`b5f824e`). 이미 푸시한 커밋 메시지 3개(`a325f8b` · `2b49e6c` · `fb07d3b`)의 「2026-10-22」는 고칠 수 없어 여기 남긴다 / 다시 안 겪으려면: 날짜는 `date` 나 커밋 시각으로 적는다
- **커밋을 이어서 도는 셸 함수가 첫 실패 뒤에도 다음 커밋을 진행했다** — `git rm` 으로 이미 지운 파일을 `git add -A -- <그 파일>` 에 넣어 「pathspec did not match」로 첫 커밋이 실패했는데, 함수가 `;` 로 이어져 있어 다음 커밋이 앞 커밋의 스테이징(지운 파일)까지 싣고 돌기 시작했다 / 해결: 훅이 도는 중에 작업을 멈추고(커밋 안 됨 확인), 남은 브라우저 2개를 끈 뒤 스테이징을 바로잡아 하나씩 다시 커밋 / 다시 안 겪으려면: 이어지는 커밋은 `&&` 로, 지운 파일은 따로 스테이징한다
- **「요청 수 0」 테스트가 아무것도 증명하지 못했다** — 처음엔 127.0.0.1 에 서버를 띄워 렌더러가 보낸 요청 수를 셌는데, 막기를 빼도 0 이라 통과했다. 카드 페이지 주소가 가짜 origin 이라 브라우저가 로컬 주소 요청을 따로 막는 것으로 보인다(원인은 확인 못 함) / 해결: 막은 주소를 결과에 남겨 직접 확인하고, 막기를 빼면 실패하는 것을 확인 / 다시 안 겪으려면: 「없어야 한다」를 보는 테스트는 일부러 깨뜨려 실패하는지 본다
- 앞 세션 기록 확인: 「사용자 결정」 표를 만들며 본 `server/src/config.ts` 의 `prompts.activeVersions` 주석이 옛 판으로 돈 측정을 근거로 적혀 있다(「실제 소재 저장 6/6, 10-18 은 5/1」 — 정정 전 숫자, devlog 2026-10-18-03). 제품 코드 주석이라 이번에 고치지 않고 아래 「다음에 할 것」에
