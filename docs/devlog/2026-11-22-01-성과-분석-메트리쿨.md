  - CLAUDE.md 「이미 내린 결정」에 올림: 예
- `#결정` **MCP 클라이언트 · OAuth 를 의존성 없이 직접 짰다** — 필요한 것이 initialize · tools/call · JSON/SSE · 401 다시 시도뿐이라 공식 SDK 를 넣는 것보다 작다. 새 npm 의존성 없음
- `#결정` **토큰은 키체인의 앱 전용 이름(internal) 하나에 base64url JSON** — 키체인 값 규칙(공백 · 따옴표 금지)을 그대로 지키려고. 4,096자를 넘으면 접근 토큰은 빼고 새로 받기 토큰만 남긴다
- `#결정` **제안의 「규칙」 문장에는 숫자를 아예 못 쓰게 했다**(지시보다 엄하게) — 규칙은 프로필에 들어가 이후 카드 · 제목 생성의 허용 출처(브랜드 프로필)가 되므로, 숫자가 섞이면 그 숫자가 다른 생성에서 근거로 통과해 버린다. 숫자는 제안 문장 · 근거에만 — **사용자 확인 필요**
- `#결정` **비율은 「게시물마다 낸 비율의 평균」**(합계 비율이 아님) — PRD FR-IN-4 의 「평균」. 도달이 큰 게시물 하나가 묶음을 끌지 않게
- `#결정` **표본 수는 지표마다** — 저장이 빈 게시물은 저장률 표본에서만 빠진다. 「사용 가능한 표본」 = 48시간 지남 + 그 지표의 분자 · 도달이 있음
- `#결정` **제목 유형 첫 판은 코드 한 함수**: 「?」 또는 「…까 · 나요 · 가요」로 끝나면 질문형(먼저 본다) → 숫자가 있으면 숫자형 → 그 외. 한글 수사는 숫자형이 아니다
- `#결정` **잇기 후보 점수에 「포함 정도」를 더했다** — 짧은 표지 제목과 긴 캡션은 자카드가 늘 작아서. 캡션 자카드와 큰 값을 쓴다. 자동으로 잇지 않으므로 기준값은 두지 않았다(순서만 정함)
- `#결정` **수락한 새 판에는 이미 만료된 성과 항목을 옮기지 않는다** — 만료된 줄이 쌓이면 직접 수정 화면의 개수 한도(말투 6 · 피할 것 8)에 걸린다. 옛 판에는 그대로 남아 이력에서 보인다. 한도가 찼으면 수락하지 않고 「하나 지운 뒤」 안내
- `#결정` **수락한 판의 job_id 는 비운다** — 처음엔 제안 작업 ID 를 넣었더니 작업 콘솔이 「다음에 할 것 제안 → 정체성 프로필 3판」으로 이었다. 판은 사용자의 수락이 만든 것이라
- `#결정` **불러오기는 작업(job)이 아니라 요청 하나**(제한 60초) — AI 호출이 아니라 작업 콘솔 · ai_runs 에 남길 것이 없다

## 오류 → 원인 → 해결
- `#트러블슈팅` **설정 API 가 앱 전용 비밀 이름까지 받아들였다**

  - CLAUDE.md 「겪은 오류」에 올림: 아니오(새로 만든 이름에서 바로 막음)
- `#트러블슈팅` **게시물 표가 1280 화면에서도 가로로 넘쳤다**
  - 증상: 8칸 표가 본문(작업 콘솔 옆 약 580px)보다 넓어 공유율 · 고치기 칸이 잘림(스크린숏에서 봄)
  - 해결: 표 대신 게시물마다 한 덩어리(머리 줄 + 글 + 이은 세트 + 수치 다섯 칸)로. 묶음 표는 390 에서 배지가 줄바꿈되게
- `#트러블슈팅` **React 린트(set-state-in-effect · 렌더 중 Date.now)**
  - 증상: `async` 함수 안 setState 를 효과에서 부르면 걸림, 정체성 화면 태그의 `Date.now()` 는 「impure」
  - 해결: 다른 화면처럼 `.then` 사슬로, 시각은 `useState(() => Date.now())`
