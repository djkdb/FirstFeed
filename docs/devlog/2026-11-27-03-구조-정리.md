## 오류 → 원인 → 해결

- `#트러블슈팅` **비교 스크립트가 화면의 「바꾸기」 단추를 눌러 시험 데이터를 바꿨다**
  - 증상: 설정 화면 비교 뒤 기준 화면 7개 중 2개(설정 · 세트 보기)가 나누기 전과 달라짐 — 티스토리 블로그 주소가 사라짐
  - 원인: 키 입력 칸을 열려고 「바꾸기」를 찾았는데, 문서 순서상 먼저 걸린 것이 블로그 주소 줄의 「바꾸기」였다. 그 단추는 누르면 주소를 지우고 저장한다(`saveBlog({ tistory: null })`, 원래 동작). 코드가 아니라 내 스크립트 탓
  - 해결: API 로 주소를 되돌리고 기준 7개가 다시 차이 0 인 것을 확인 → 비교 스크립트가 **GET 이 아닌 요청은 모두 막게** 고쳐 다시 비교
  - 다시 안 겪으려면: 화면을 눌러 보는 비교 · 시뮬레이션은 쓰기 요청을 막고 시작한다
  - docs/errors.md 「겪은 오류」에 올림: 아니오(비교 도구 쪽 일, 앱 코드의 모양이 아님)
