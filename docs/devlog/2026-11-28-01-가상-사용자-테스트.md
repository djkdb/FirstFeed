## 어떻게 했나
- 빈 데이터 폴더 + 실제 AI 로 앱을 띄움. 클라우드 세션 로그인을 받는 임시 서버 파일을 만들어 쓰고 지움(커밋 안 함 — 11-09 시뮬레이션과 같은 예외)
- 실제 Chromium 하나를 띄워 두고 단계마다 붙어 같은 탭을 이어 씀. 단계마다 걸린 시간 · 화면 글자 · 스크린숏을 남김(스크린숏은 레포 밖)
- 페르소나: 간호학과 3학년 · 자취 요리 기록 계정(AI 생성 — 실제 사람 아님). 11-09 의 홈카페 직장인과 다른 **비IT 분야**로 골랐다 — 설문 · 안내가 IT 쪽에 치우쳤는지 보려고
- 진행 순서는 `user-test-record.md` 「진행 방법」과 같다

## 결과
- 세 과제 모두 성공. **AI 대기 실측 약 7분 50초**, 사람 조작 추정 약 16~22분 → 첫 결과까지 **약 24~30분(추정)**
- 막힌 곳 6개 — 가장 큰 것은 **「프로필 만들기」가 두 번 거절되며 2분 22초를 기다린 것**(버튼 노출 조건 「최소 3문항」 ≠ 통과 조건 「근거 축 3개」)
- 자세한 표: [user-test-record.md](../process/user-test-record.md)

## 결정
- `#결정` **AI 가상 사용자 기록은 실제 사용자 기록과 같은 문서에 두되, 맨 앞에 「실제 사용자 아님」을 적는다** — 같은 양식으로 비교할 수 있게 하되, 확인(validation)의 근거로 섞이지 않게
- `#결정` **이번에는 고치지 않는다** — 범위 정리(PRD v0.3) 전이라, 막힌 곳은 요구사항 카드 후보로만 남긴다

## 오류 → 원인 → 해결
- `#트러블슈팅` 브라우저 조작 스크립트에서 경로를 `#/templates` 로 잘못 써 홈으로 돌아감 — 앱 문제가 아니라 진행 스크립트 실수. 기록에서 뺐다
- `#트러블슈팅` 소재 「메모」 칸을 textarea 로 찾다가 못 찾아(입력 칸이 다른 종류) 메모를 비운 채 진행 — 진행 스크립트 실수. 카드 결과에는 영향 없음(메모는 선택)

## 확인 못 한 것

- 맥(기준 브라우저)에서의 템플릿 · 카드 넘침 판정 — 이 환경은 Chrome 이 잡혔다
