# 사용자 테스트 기록

> 이 문서는 **15분 사용자 테스트**의 진행 방법과 기록을 모은다. 기록마다 **누가 했는지(실제 사람 / AI 가상 사용자)**를 맨 앞에 적는다.
> AI 가상 사용자 기록은 **실제 사용자 측정이 아니다** — 확인(validation)의 근거로 쓰지 않고, 실제 테스트 전에 막힐 곳을 미리 찾는 점검(Ch.7 의 알파 · 시나리오 테스트)으로만 쓴다.

## 진행 방법 (실제 테스트도 같은 순서로)

- 대상: 인스타를 처음 시작하려는 사람 1명. 진행자는 옆에서 **돕지 않고 기록만** 한다
- 시작 전에 읽어 줄 말: 「이 앱을 처음 쓰는 사람이 어디서 막히는지 보려는 거예요. 막히는 건 앱 탓이니 편하게 하세요. 생각나는 걸 소리 내어 말해 주세요.」
- 막혔을 때 진행자가 해도 되는 말: 「지금 뭘 하려고 하세요?」 · 「뭐가 보이세요?」 / 하면 안 되는 말: 어디를 누르라는 말, 화면 설명
- 과제 3개
  1. 설문부터 브랜드 프로필 받기
  2. 카드뉴스 1세트 만들기(브랜드 · 템플릿 포함)
  3. 캡션 · 업로드 폴더 받기
- 끝나고 묻는 것: 가장 헷갈린 곳 · 다시 쓸지 · 9칸 격자가 한 계정처럼 보이는지 · 기다린 시간이 어땠는지 · 빼도 될 것 같은 화면
- 기록: 과제별 성공 여부 · 걸린 시간 · 첫 결과(업로드 폴더)까지 시간(PRD 기준 30분) · 막힌 곳(화면 · 하려던 일 · 심각도) · 참가자가 한 말 그대로
- 심각도: **끝까지 못 감** / **한참 헤맴**(1분 넘게) / **잠깐 멈춤**
- 이름 · 연락처는 적지 않는다(A · B …). 공개 레포다

- **AI 대기는 실측**이다(앱 작업 콘솔과 브라우저 조작 기록).
- **사람 조작 시간은 추정**이다. AI 는 읽고 입력하는 시간이 사람과 다르다. 직접 입력한 글자 546자를 분당 60~90자로 입력, 화면마다 읽기 20초~2분으로 잡았다. 소재 원문(약 380자)은 휴대폰 메모에서 붙여 넣은 것으로 보았다.

### 잘 된 것

- 꼬리질문이 설문 답(간호학과 · 자취 요리 · 실습)을 받아 1번부터 그 사람 이야기로 물었다. 예시 답도 그 분야로 나왔다
- 프로필의 축 3개마다 인터뷰 답 인용이 붙어 「왜 이 축인지」가 보였다. 「피할 것」에 직접 말한 「다이어트 식단 이야기」가 들어감
- 바이오 후보가 직접 한 말(「첫 실습 때 편의점 도시락만…」)에서 나왔다
- 카드 본문의 금액 · 품목이 소재와 같았다(합계 24,130원 · 품목 6개). 소재에 없는 숫자 0
- 업로드 폴더가 01 → 07 순서로 정리되고 캡션.txt 가 함께 들어감

### 한계

- **사람이 아니다.** 진행자 역할 AI 가 앱 구조를 이미 알고 있어(코드 · 문서를 읽음) 실제 처음 쓰는 사람보다 덜 헤맸을 가능성이 크다. 특히 ③ ⑤ 는 실제 사람에게 더 클 수 있다
- 사람 조작 시간은 추정이다. 「첫 결과까지 30분」 판정은 실제 사용자 측정으로만 한다
- 페르소나 1명 · 1회. 감정(지루함 · 불안)은 잴 수 없다
- 환경 차이: 이 환경에서는 기준 브라우저가 아닌 Chrome 이 잡혀 「찍은 브라우저: … 기준 브라우저 아님」 문구가 보였다. 맥에서는 보이지 않으므로 막힌 곳에서 뺐다
