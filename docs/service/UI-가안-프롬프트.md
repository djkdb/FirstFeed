> 쓰는 법: 아래 「프롬프트 본문」을 통째로 붙여 넣고, 고칠 화면의 지금 스크린숏을 같이 올린다. 한 번에 화면 하나씩 받는 편이 결과가 좋다(맨 아래 「이어서 보낼 말」).
> GPT 그림 생성은 한글이 깨지기 쉬워서 **HTML 한 파일**로 받는 것을 기본으로 했다 — 브라우저로 열면 바로 가안을 볼 수 있다.

## 프롬프트 본문

```
너는 한국어 웹앱의 시니어 프로덕트 디자이너다. 아래 앱의 화면 가안을 만들어 줘.

# 앱
- 이름: 퍼스트피드(FirstFeed). 인스타를 처음 시작하는 사람이 「정체성 찾기 → 브랜딩 → 템플릿 고정 → 카드뉴스 만들기 → 30일 뒤 내 계정 미리보기 → 성과 분석」을 한 곳에서 하는 로컬 웹앱
- 대표 기능: 게시물 하나 올리기 전에 「30일 뒤 내 계정」(프로필 + 3열 격자)을 먼저 보여 준다
- 원칙: AI 가 지어낸 숫자를 보이지 않는다. 모르는 값은 「입력 안 됨」(0 으로 쓰지 않음). 만든 게시물과 계획만 있는 게시물을 화면에서 구분한다(계획 칸은 점선 · 「계획」 배지). 팔로워 수 같은 없는 숫자는 「–」
- 코드: https://github.com/djkdb/FirstFeed (화면은 app/src, 디자인 값은 app/src/styles.css). 내가 올린 스크린숏이 지금 모습이다

# 화면 틀(지금 그대로 지킬 것)
- 왼쪽 묶음 메뉴(계정 칸 · 오늘 올릴 것 · 시작하기 1 정체성 2 브랜드 3 템플릿 · 만들기: 카드뉴스 · 릴스 · 30일 뒤 미리보기 · 성과 · 설정: 설정 · 점검) + 가운데 본문(최대 960px) + 오른쪽 작업 콘솔(AI 작업 진행 · 한 일 목록)
- 860px 아래(휴대폰)는 왼쪽 메뉴가 위쪽 가로 줄로 바뀐다

# 디자인 규칙(꼭 지킬 것)
- 앱 화면은 무채색만. 색은 사용자 브랜드(카드 그림 · 미리보기 폰 화면 안)에만 쓴다. 파란 강조색 · 크림색 바탕 금지
- 밝은 판: 바탕 #f2f2f4, 판(카드) #ffffff, 옅은 면 #f4f4f6, 선 #e7e7ea, 글자 #18181b, 흐린 글자 #5f5f68, 성공 #1d7a46(옅은 면 #e7f5ec)
- 어두운 판: 바탕 #0e0e11, 판 #16161a, 면 #222228, 선 #2a2a31, 글자 #f4f4f5, 흐린 글자 #a1a1aa
- 채운 단추 = 검정 바탕 + 흰 글자(어두운 판은 밝은 회색 바탕 + 검정 글자). **채운 큰 단추는 화면마다 하나**(그 화면의 주요 동작), 나머지는 테두리 · 글자 단추
- 단추 높이 40 / 작은 단추 32 / 큰 단추 52, 모서리 32=8px · 40=10px · 52=14px. 판 모서리 넉넉히, 그림자 거의 없음(얇은 선 + 여백)
- 글꼴 Pretendard. 글자 명암비 4.5:1 이상
- 문구는 쉬운 한국어 존댓말, 짧게. 안 되는 단추에는 왜 안 되는지를 옆에 한 줄로

# 이번에 풀 문제(화면 점검에서 찾은 것)
1. 브랜드 탭(프로필 없을 때): 경고는 뜨는데 아래 생성 단추 · 캐릭터 만들기가 다 눌린다 → 프로필이 없으면 섹션을 접고 「정체성부터 하기 →」 하나만
2. 브랜드 탭: 한 쪽이 6,337px · 단추 179개 · 채운 단추 7개. 「아이디·이름·바이오 후보」 「색·폰트·그림」 「프로필 사진」 「내 캐릭터 만들기」 「리틀리 채우기」가 한 줄로 이어짐 → 하위 탭(글 · 색과 글꼴 · 그림 · 캐릭터)으로 나누고 단계마다 「고른 것 · 다음 할 일」이 보이게. 리틀리는 설정으로
3. 템플릿 탭: 시안 11개마다 채운 「이 틀로 고정」 단추. 「한눈에 보기」 표지 그림이 늦게 뜸 → 한눈에 보기에서 고르면 그 시안만 크게 펼치고 고정 단추 하나. 그리는 동안은 자리 표시(뼈대)
4. 릴스 첫 화면: 할 일 안내가 없고 예시 글이 영상 안에 그려져 있음 → 「1 대본 붙여 넣기 → 2 장면·모션 → 3 영상 뽑기」 안내와 시작 단추 하나
5. 휴대폰 위쪽 메뉴: 4개만 보이고 나머지가 화면 밖인데 표시가 없음
6. 휴대폰 「작업 콘솔」 떠 있는 단추가 내용을 가림
7. 홈 「30일 계획」: 9줄마다 「올렸어요」 「하루 미루기」 반복 → 오늘 · 다음 칸만 단추, 나머지는 줄을 누르면 펼침. 「계획」 배지는 단추처럼 안 보이게
8. 넓은 화면 작업 콘솔: 도는 작업이 없어도 오른쪽 4분의 1 을 차지 → 쉴 때는 접힌 상태
9. 카드뉴스 「만든 세트」: 글 한 줄 목록 → 표지 작은 그림 + 「11/24 칸에 이음 · 올림」 배지
10. 성과 「게시물」: 게시물마다 「세트 잇기」 선택 상자 → 잇기는 위 「잇기 확인」에서만, 목록은 최근 5개 + 더 보기
11. 왼쪽 메뉴 번호(1~4)와 홈 처음 화면 5단계 번호가 다름
12. 회색(안 되는) 단추에 이유가 없음

# 만들어 줄 것
- 내가 고른 화면 하나를 **HTML 한 파일**(CSS 포함, 바깥 라이브러리 없이, Pretendard 는 시스템 글꼴로 대체 가능)로. 위쪽에 「밝게 / 어둡게」 · 「1440 / 390」 전환 단추를 둬서 네 모양을 한 파일에서 볼 수 있게
- 예시 데이터는 지어낸 가상의 계정으로(실존 인물 · 브랜드 이름 금지), 숫자는 예시라는 게 보이게 둥글게
- 가안은 **2안**: A = 지금 구조를 지키며 정리, B = 더 과감하게 흐름을 바꾼 안
- 파일 아래에 짧게: 무엇을 바꿨는지(위 문제 번호와 연결) · 왜 · 개발할 때 주의할 점
```

## 이어서 보낼 말(화면 하나씩)

- 「2번(브랜드 탭)부터. 스크린숏 첨부. A · B 2안으로.」
- 「3번(템플릿 탭). 한눈에 보기에서 고르는 흐름으로.」
- 「홈 화면에 7 · 8 · 11 · 12번을 같이 반영해서.」
- 「휴대폰(390)만 따로: 5 · 6 · 10번.」
- 그림으로도 보고 싶으면: 「방금 HTML 의 A안을 1440 밝은 판 한 장 그림으로. 글자는 최소로, 배치와 위계가 보이게.」(그림은 한글이 깨질 수 있다)
