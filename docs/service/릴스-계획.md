### ffmpeg (실험 b)
- 이 맥: `/opt/homebrew/bin/ffmpeg` · `ffprobe` **8.1.2**(Homebrew, `brew info`: 안정판 9.0.2 있음). 인코더 `libx264` · `h264_videotoolbox` · `aac` 있음
- 라이선스: 이 빌드는 `--enable-gpl --enable-libx264 --enable-version3`(GPL 빌드). **앱은 ffmpeg 를 같이 넣지 않고 사용자 컴퓨터에 깔린 것을 별도 프로그램으로 부른다** — 배포하지 않으므로 GPL 조건이 앱 코드에 걸리지 않는 방식(법률 판단 아님 — 「확인 필요」 표시로 남김). 앱이 만든 mp4 자체는 라이선스 문제 없음(코덱 특허는 확인 못 함)
- 설치 안내(doctor 문구 후보): macOS `brew install ffmpeg`, Windows 는 공식 사이트(ffmpeg.org) 의 빌드 안내 — Windows 경로는 실제로 깔아 보지 않음(확인 못 함)

## 4. 흐름 (미노출 · 캐릭터)

1. **입력**: 소재(또는 만든 카드 세트) — 카드 만들기와 같은 소재 · 프로필 · 고정 템플릿
2. **대본** `prompts/reel_script/v1.md`(새 판, 이전 프로그램 프롬프트 안 씀): 문장 단위 `[{text, on_screen?, gloss?}]` + 훅 + 표지 문구. 규칙(코드): 근거 대조 · 풀이 표시가 글에 있는지 · 문장 수 · **추정 길이 15~30초**(초당 글자 수 설정) · 화면 글자 길이(고정 틀 칸 예산). 자기 평가는 카드와 같은 기준(fact · broken 만 재작성)
3. **TTS**: 문장마다 한 번(문서상 시간 정보가 없어서). 같은 글 · 목소리 · 속도면 다시 부르지 않는다(캐시). 무료 판 동의가 없거나 키가 없으면 건너뛰고 무음
4. **타임라인**: 문장 길이(ffprobe) + 문장 사이 쉼(설정) → 장면 시작 · 끝. 무음이면 추정 길이
5. **모션**: 브랜드 템플릿의 9:16 장면(HTML/CSS 애니메이션) — 축 색 변형(`pillarCoverLook`) · 명암비 4.5:1 규칙 재사용, 제목 · 자막은 **위아래 240px 가림 안**(결정 2026-10-18). 프레임은 실험 c 처럼 애니메이션 시각을 정해 찍는다(같은 입력 = 같은 영상). 글꼴 대체 검사 · 글 칸 넘침 검사는 카드 렌더링 것을 그대로
6. **합치기**: ffmpeg — 프레임 → H.264, 문장 오디오를 이어 AAC, 1080×1920 · 30fps · `+faststart`. 길이 · 무음 구간 검사(FR-MK-6 의 「길이 · 음량 · 멈춤」)
7. **업로드 폴더** · **폰으로 받기**(지금은 카드 PNG 만 내준다 → mp4 · srt 도 목록에 넣도록 넓힘) · 업로드 화면에 「인스타에서 AI 정보 표시를 켜세요」

예상 시간(실험 값으로): 프레임 캡처가 영상 1초당 약 2.7초(실험 c) → 30초 릴스 ≈ 80초 + 인코딩. TTS 는 실험 a 뒤에 채운다

## 4-2. 흐름 (노출 — 내가 찍은 영상으로 릴스 굽기, 2026-11-05 결정)

1. **대본 · 컷 목록**: 대본은 미노출과 같은 과제 · 같은 근거 규칙. 다만 **컷 하나 = 대본 한 문장**으로 짜고, 컷마다 「말할 문장 · 무엇을 찍을지(얼굴 · 손 · 화면 등) · 예상 길이(글자 수 ÷ 초당 글자 수)」. 찍기 안내: **「한 컷에 한 문장만 말하고 끊어 찍기 · 세로로 · 1배속 그대로」**
2. **컷 올리기**: 컷 칸(문장마다 한 칸)에 하나씩, 또는 여러 개를 한 번에 놓으면 **파일 이름 순서**로 칸에 넣고 사용자가 칸끼리 바꿀 수 있다. 형식은 파일 앞부분(매직 바이트 — mp4 · mov 의 `ftyp`)으로, 이름은 서버가 짓고, 크기 상한은 설정값(브랜드 그림 올리기와 같은 원칙 — 결정 2026-10-14). 폰에서 컴퓨터로 옮기는 법은 0-15
3. **이 컴퓨터에서 처리**(ffmpeg — 앱이 넣지 않고 사용자 것을 부른다):
   - 컷마다: 회전 정보대로 세로로 맞추고(가로 컷은 경고) 1080×1920 으로 맞추기(남는 곳은 자르기 — 얼굴이 잘리는지는 확인 컷 판에서 사람이 봄), 30fps 고정. **재생 속도는 바꾸지 않는다**(교훈 9 — 앱이 컷을 느리게 하지 않는다)
   - 앞뒤 무음 다듬기: 무음 판정 음량 · 남길 여백은 **설정값**(`reels.trimSilenceDb` · `reels.trimPadSec` — 처음 값은 실제 컷 몇 개로 재서 정한다, 감으로 넣지 않음)
   - 컷 목록 순서대로 잇기. **자막 시간 = 다듬은 컷 길이**(한 컷 = 한 문장이라 음성 인식 없이 정확). 자막 글은 대본 문장(다르게 말했으면 0-17)
   - 화면 글자 · 자막 · 워드마크는 미노출 경로와 **같은 브랜드 틀**(같은 가림 영역 · 같은 넘침 검사 · 같은 글꼴 확인)로 투명 PNG 를 그려 컷 위에 얹는다. 얹는 계산은 RGB 에서(교훈 15)
   - 음량 맞추기(0-10), 끝 시각은 `-t`(교훈 13), 배경음 없음(교훈 17)
4. **경고(반려하지 않음)**: 컷 수 ≠ 문장 수(빈 칸 번호 · 남는 컷) · 다듬은 컷이 예상 길이보다 **너무 짧거나 너무 길다**(배율은 설정값 — 처음 몇 편을 재서 정함) · 가로 컷 · 소리가 거의 없는 컷 → **「N번 컷을 다시 찍어 보세요」**. 빈 칸이 있어도 있는 컷만으로 굽을 수 있다(그 문장은 자막도 빠진다고 알림)
5. 확인 컷 판(FR-MK-12) · 굽기 · 1초 판 · 「끝까지 봤어요」 · 업로드 폴더는 미노출과 같은 화면. 표지는 고정 틀의 릴스 표지, 또는 **컷의 한 장면을 표지 바탕으로**(그림 바탕 표지와 같은 함수 · 명암비 검사 — 결정 2026-10-18. 시안 F 가 아닐 때도 이 경우만 쓸지는 구현 때 확인)
6. **얼굴 원본**: 이 컴퓨터의 데이터 폴더에만(레포 밖 · `.gitignore` 의 `data/`). **AI 에게 프레임을 보내는 기능은 만들지 않는다**(필요해지면 그때 동의를 받고). 「폰으로 받기」는 완성된 mp4 · 표지 · 자막만 내준다(원본 컷은 안 내줌). 지우는 때는 0-16

## 5. 키 · 개인정보 · 동의

- **키**: 사용자 키는 **OS 키체인**(작업 규칙 · 결정 2026-10-13). 앱에 아직 키체인 코드가 없다(FR-AI-7 S) — macOS 는 `security` 명령(키체인 접근)으로 시작하고 Windows 는 나중(확인 못 함). 개발용은 `.env`(커밋 안 함, `.gitignore` 확인). **앱에 개발자 키를 넣지 않는다**
- **키가 없거나 무료 판이 끝났으면**(401 · 402 · 무료 모델 거절 등 — 실제 응답 모양은 실험 a 뒤에 적는다): 대본 · 무음 모션 · 자막까지 만들고 「음성은 만들지 못했어요 — 이유 · 할 일」 안내. 유료 모델로 저절로 바꾸지 않는다(헤더 값이 틀리면 유료 `s2.1-pro` 로 떨어진다는 문서 내용 때문에 **모델 값을 코드가 고정하고 응답의 모델을 확인**)
- **동의**: 무료 판은 「요청이 모델 개선에 쓰일 수 있음」을 화면에 알리고 체크해야 TTS 를 부른다(체크는 저장, 끄면 무음). 대본에 개인정보가 들어가지 않게 기존 개인정보 검사(redact)를 보내기 전에 한 번
- **얼굴이 나오는 컷(노출 경로, 2026-11-05)**: 원본은 이 컴퓨터 밖으로 보내지 않는다 — AI(프레임) · TTS · 폰으로 받기 어디에도. 자세한 것은 4-2장 6
- **목소리**: 이번 범위는 기본 목소리만. 음성 복제는 만들지 않고, 나중에 넣으면 「본인 목소리만」 안내 + 동의
- **업로드 안내**: 「인스타에서 AI 정보 표시를 켜세요」(정확한 메뉴 이름은 사용자 확인 뒤)

## 9. 키 넣는 법 (채팅에 붙여 넣지 않기)

   ```sh
   cd ~/Claude/FirstFeed && printf 'FISH_AUDIO_API_KEY=%s\n' "$(pbpaste)" >> .env && chmod 600 .env && grep -c '^FISH_AUDIO_API_KEY=' .env
   ```
   마지막 숫자가 `1` 이면 들어간 것. `.env` 는 `.gitignore` 에 있어 커밋되지 않는다(`git check-ignore -v .env` 로 확인)

## 11. 초보자 화면 흐름 (2026-11-05 — 노출 경로 결정 반영해 다시 씀)

한 화면에 **누르는 것은 하나**(취소 · 뒤로는 빼고 셈). AI 호출은 **그 결과가 보이는 단계**에 적었다(앞 단계의 단추가 시작한다). 수는 **재작성 없을 때 → 최악**(생성 + 자기 평가, 재작성 2회 한도 — 결정 2026-10-13. JSON 다시 요청 1회는 셈에서 뺐다). AI 는 모두 사용자 구독의 Claude Code CLI 라 외부 서비스로 세지 않는다. 시간은 실측이 없는 단계는 적지 않는다.

세 경로가 **같은 8단계 모양**이고 4단계(재료)만 다르다. 캐릭터 경로는 미노출과 같고 장면에 사용자가 올린 캐릭터 그림이 들어간다.

### 새 정할 것

18. **받아쓰기** — 노출 경로는 「한 컷 = 한 문장, 음성 인식 없음」으로 정했다(2026-11-05). 툴의 받아쓰기는 이 컴퓨터의 faster-whisper 라 밖으로 나가지 않는다. (가) **넣지 않는다**(지금 결정 그대로 — 자막은 대본 문장, 다르면 사람이 고침) / (나) **선택 기능**으로 넣는다(설치한 사람만, 이 컴퓨터에서만 — 「실제로 한 말」 자막). 제안: **(가)** — 자막이 대본과 같아야 근거 규칙이 의미가 있고, 설치 단계가 하나 는다
19. **영상 엔진 Remotion** — 4장은 「브라우저로 시각 정해 찍기 + ffmpeg」였다. Remotion 은 같은 방식(시각 정해 찍기)을 묶어 주고 편집 화면 미리보기(Player)와 굽기가 **같은 컴포지션**이라 화면 = 영상이 보장된다. 대신 의존성이 커지고(웹팩 묶기 · 렌더링 브라우저를 처음 한 번 내려받음 — 「브라우저 자동 설치는 F」 결정과 부딪힘), **라이선스**가 붙는다: 개인 · 직원 3명 이하 회사 · 비영리는 무료(상업 포함), 그보다 큰 회사는 회사 라이선스(`node_modules/remotion/LICENSE.md` 원문, 2026-11-06 확인). FirstFeed 를 쓰는 사람이 큰 회사면 그 사람에게 라이선스가 필요한지, 서비스화 때 어떻게 되는지는 **확인 필요**. 제안: **Remotion 으로**(편집 화면이 이 기능의 핵심이라), 렌더링 브라우저는 앱이 받지 않고 이미 있는 Playwright Chromium 을 넘긴다(`browserExecutable` — 툴에서 실제로 돌려 확인함), 라이선스는 서비스화 계획에 적는다
20. **편집 화면 범위** — 툴의 기능(4줄 타임라인 · 끌기 · 자르기 · 자석 · 되돌리기 · 가림 경고 · 글자 속성 · 장면 갈아끼우기 · 배경 · 원본 문구 · 메모)을 **전부** 넣을지, 이번엔 **자막 · 화면 글자 · 장면 길이 다듬기만** 넣을지. 제안: **전부**(이미 동작을 확인한 코드라 옮기는 비용이 크지 않다), 다만 「위에 얹기」 · 소리 줄은 미노출 경로에서만 보인다(노출 경로는 사람이 찍은 영상이 메인)
