## 언제 · 어떻게 만들었나

- **만든 날짜: 2026-10-20** (파일 이름과 원본 머리의 날짜. xlsx 의 만든 시각은 2026-10-20 02:54 UTC)
- **방법**: 사용자가 매니패스트에 자료를 넣고 PRD → 기능명세서 → 유저플로우 → 화면 시안 순서로 만들어 내려받았다. PRD 원본 「문서 안내」에 따르면 넣은 자료는 자료 1(PRD v0.1) · 자료 2(개발 결정) · 자료 3(2026-10-18 기준 구현 상태, 사용자 검토 전) · 자료 4(「정해진 것」과 1단계 사용자 답변)이고, 13장에 「사용자 2단계 요청」이 근거로 나온다. 자료 2·3·4 가 레포의 어느 파일인지는 원본에 적혀 있지 않다(확인 못 함)
