## 언제 · 어떻게 만들었나

- **만든 날짜: 2026-10-20** (파일 이름과 원본 머리의 날짜. xlsx 의 만든 시각은 2026-10-20 02:54 UTC)
- **방법**: 사용자가 매니패스트에 자료를 넣고 PRD → 기능명세서 → 유저플로우 → 화면 시안 순서로 만들어 내려받았다. PRD 원본 「문서 안내」에 따르면 넣은 자료는 자료 1(PRD v0.1) · 자료 2(개발 결정) · 자료 3(2026-10-18 기준 구현 상태, 사용자 검토 전) · 자료 4(「정해진 것」과 1단계 사용자 답변)이고, 13장에 「사용자 2단계 요청」이 근거로 나온다. 자료 2·3·4 가 레포의 어느 파일인지는 원본에 적혀 있지 않다(확인 못 함)
- 파일 이름의 「제목 없음」·「(1)」·「.md.md」는 매니패스트가 붙인 그대로다(원본이라 바꾸지 않음)

## 화면 시안(`새_플로우_1.html`)이 PRD v0.2 · 결정과 다른 점

> 화면 시안은 매니패스트가 그린 **참고용 와이어프레임**이다. 화면을 만들 때는 아래를 시안이 아니라 [PRD v0.2](../../PRD.md) · [CLAUDE.md 결정](../../../CLAUDE.md) 대로 한다. 시안 속 계정·날짜·숫자는 예시 값이다. 확인 방법: HTML 의 화면 글자를 뽑아 PRD·코드와 대조(2026-10-20)

| 화면 | 시안 | PRD v0.2 · 결정 · 지금 앱 |
|---|---|---|
| 작업공간 초기화(첫 화면) | 「브랜드 이름」 입력 칸 + 「작업공간 생성」 | 첫 화면에서 브랜드 이름을 받는 단계가 없다. 로그인 없이 로컬 1명·브랜드 1개로 바로 시작(FR-AC-1)하고, 이름·아이디는 브랜딩 키트에서 후보를 고른다(FR-BR-1) |
