### 1-3. 이번 버전의 범위

| 구분 | 요구사항 |
| --- | --- |
| 최종까지 반드시 | FR-PB-1, FR-MK-3, FR-MK-7, FR-IN-2~6, FR-OP-1·2·4·5(대외활동 공지는 붙여넣기·캡처만) |
| 여유가 있으면 | FR-DS-1·2·5(키워드 + AI 웹 검색만), FR-MK-4, FR-PB-3, FR-OP-6, FR-OP-7, Codex·Gemini 지원 |
| 이번 버전에서는 하지 않음 | FR-IN-1, FR-PB-2, FR-DS-4, FR-OP-3, FR-MK-6, FR-AC-2~5, FR-DS-3 |

- 나누는 기준: 외부 승인·계정 연동(인스타 공식 API, Gmail OAuth 등)이 필요하면 "하지 않음", 기본 흐름에 필요하면 "반드시".
- 하지 않는 요구사항은 지우지 않고 "향후 계획"으로 남긴다.
- 11월 29일까지 성과 분석(FR-IN-2~6)이 끝나지 않으면 대외활동(FR-OP-1·2·4·5)을 "하지 않음"으로 옮긴다.

### 1-4. 대상 사용자

- 이번 버전의 사용자는 "Claude를 구독하고 있는 인스타 입문자"다. 대표 사용자(민지)는 그대로 둔다.
- 첫 사용자 후보 1명이 있다(Claude 유료 요금제 사용, 최근 인스타 계정 개설). 인스타를 시작한 주변 친구들에게도 권할 예정이다.

### 1-5. AI 연결 방식 (기본 흐름이 완성된 뒤, 시간이 남을 때)

- AI를 연결하지 않는 사용자: 단계마다 쓸 프롬프트를 가이드로 보여 주고, 복사해서 다른 AI나 시스템 프롬프트에 붙여 넣어 쓰게 한다.
- AI를 연결하는 사용자: Claude Code CLI와 API 키 중에서 고른다. Codex·Gemini도 나중에 연결할 수 있게 한다.

### 1-6. 설치

- 더블클릭 실행(F)보다 먼저, Node 버전과 Claude 로그인 여부를 확인하고 다음 할 일을 알려 주는 점검 명령(예: npm run doctor)과 한 번에 실행하는 명령을 만든다.
