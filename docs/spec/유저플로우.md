**원본에서 고친 것 (2026-10-20)**
1. S 기능 노드를 점선으로 구분
2. 「자료 올리기 화면 → 브랜드 프로필 초안」 화살표 추가(`n26 --> n19`) — 원본엔 자료 올리기에서 나가는 화살표가 없었다
3. 「풀이·비유 사용자 확인 → 창고 화면」 화살표 추가(`n70 --> n80`) — 원본엔 만들기에서 창고로 가는 길이 고정댓글·DM 옵션(S)을 거치는 것뿐이라, 점선으로 바꾸면 기본 흐름이 S 기능을 지나게 된다
