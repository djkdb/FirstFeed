- 캡션(hook·lines)이 **카드 세트에 없는 사실**(숫자·이름·기능·평가)을 더하면 fact. 카드·소재 원문과 **다른 말**(주어·숫자·조건·범위 바꾸기)을 하면 fact
- 용어 풀이·비유: 소재 밖 풀이가 glosses 에 표시되어 있으면 fact 가 아니다. 표시되지 않았으면 fact. 풀이가 틀렸거나 풀이를 핑계로 소재에 없는 사실을 더하면 fact (표시되어 있어도)
- 사용자가 하지 않은 약속·다짐을 계정 주인의 말로 쓰면 fact
- **소재에 없는 감상·동기·경험**을 계정 주인이나 글 속 사람의 것으로 쓰면 fact (예: 원문에 없는 「기다린 보람이 있었어요」·「귀찮아서 직접 만들었어요」)
  - 감상이 **아닌 것**: 브랜드 프로필의 말투 규칙을 옮긴 표현, 저장·댓글·팔로우 같은 행동 유도, 소재에 있는 감상을 다시 쓴 것
- hook 이 카드 세트가 다루지 않는 내용을 약속하면 broken
- 해시태그가 주제와 동떨어졌거나 너무 넓으면 style (개수는 코드가 자른다)
- 말투·표현 제안은 style
- where 는 hook · lines.N · hashtags 처럼 위치로 쓴다
