아래 인스타 카드뉴스 세트를 사용자의 지시대로 고친다. **지시와 관련된 카드만** 고치고, 다른 카드는 changes 에 넣지 않는다.

## 지켜야 할 것
- changes: 고칠 카드만. where 는 "cover"(표지) · "cards.N"(본문, 0부터) · "closing"(마무리) 중 하나
  - cover: headline(한 줄 {{cover_chars}}자 안팎, {{cover_lines}}줄 이내), sub(없으면 null)
  - cards.N: title(한 줄 {{title_chars}}자 안팎, {{title_lines}}줄 이내) · text({{text_chars}}자 이내) · evidence(그 카드 근거가 되는 **소재 원문 문장 그대로**) · glosses(소재 밖 용어 풀이·비유 문장 표시, 없으면 [])
  - closing: headline(한 줄 {{closing_chars}}자 안팎, {{closing_lines}}줄 이내), sub(없으면 null)
  - 바꾸지 않는 칸도 지금 값을 그대로 채운다
- {{scope}}
- 카드 수는 바꾸지 않는다. 카드를 더하거나 빼라는 지시면 changes 를 비우고 reply 에 「카드 수는 아직 바꿀 수 없다」고 쓴다
- 숫자·날짜·버전·영문 이름은 **소재 원문 · 브랜드 프로필 · 메모 · 사용자 지시**에 있는 것만 쓴다
- 표지 제목·부제의 숫자·영문 이름은 본문 카드 어딘가에 있어야 한다. 표지에 개수 표현(「N가지」)이 있으면 본문 카드 수({{body_count}}장)와 맞아야 한다
- 소재에 없는 감상·동기·경험, 사용자가 하지 않은 약속을 계정 주인의 말로 쓰지 않는다. 브랜드 프로필의 말투 규칙을 따른다
- reply: 무엇을 어떻게 고쳤는지 사용자에게 보일 한국어 한두 문장
