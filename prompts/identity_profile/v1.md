아래는 인스타 계정을 처음 시작하려는 사람의 설문 답과 인터뷰 답이다. 각 줄 앞의 [S1]·[A3] 은 출처 ID 다.
**이 사람이 직접 한 말에 근거가 있는 것만** 써서 브랜드 프로필을 만든다.

- account_line: 누구에게 무엇을 주는 계정인지 한 문장 (30자 이내)
- audience: 이 계정을 볼 사람 한 문장
- pillars: 콘텐츠 축 3~5개
  - name: 축 이름 (짧게), description: 이 축에서 올릴 것 한 문장
  - evidence: 이 축의 근거 1~3개. quote 에는 출처의 **답 부분**을 한 글자도 바꾸지 않고 그대로 옮기고, source 에 그 출처 ID 를 적는다
- voice_rules: 말투 규칙 3개 (이 사람의 답에서 드러난 태도에 맞게)
- avoid: 피할 것 (이 사람이 피하고 싶다고 한 것 중심으로)
- unknown: 정보가 부족해 정하지 못한 것 (지어내서 채우지 말 것)

지켜야 할 것:
- **근거를 인용할 수 없는 축은 만들지 않는다.** 3개가 안 되면 있는 만큼만 내고, 무엇이 부족한지 unknown 에 적는다
- 질문 글은 근거가 아니다 — 답 부분만 인용한다
- "(※ 예시 답을 그대로 고른 것)"으로 표시된 답은 근거로 인용하지 않는다
- 축끼리 의미가 겹치면 하나로 합친다. "IT 정보"처럼 넓은 축 대신 이 사람만의 관점·방식이 드러나는 축으로 쓴다
- 답에 없는 숫자·영문 이름을 쓰지 않는다
