# references — 디자인 참고 자료

기본 템플릿 시안(FR-TP-1)을 만들 때 **참고만** 하는 자료를 둔다. 그대로 따라 하지 않는다 — 다른 사용자의 브랜드에도 맞아야 하기 때문.

- `card.html.j2` — 운영자 본인 계정(@zun_it_)의 실제 카드 템플릿 코드(Jinja). 표지·본문(배치 여러 갈래)·마무리·릴스 표지가 한 뼈대이고, 주석에 실제로 겪은 함정(줄바꿈·flex 넘침·폰트 체인·배지 대비 등)이 적혀 있다. 본인 계정이라 공개 커밋 자료
  - 참고 방식(CLAUDE.md 결정 2026-10-15): 구조와 함정은 가져오고, 계정 고유 값(배경 #0A0C10·강조색·워드마크 ZUN)은 브랜드 키트 값으로 바꾼다
- 캡처를 넣을 때: 파일 이름은 `01-표지.png`, `02-본문-목록형.png` 처럼 번호 + 종류
- **이 레포는 공개다.** 다른 사람의 얼굴·이름·연락처가 보이는 자료는 가리거나 넣지 않는다
