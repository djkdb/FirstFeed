2. [이유 · 글로 답하기] 시중에 가계부 앱이 많은데, 퇴근 후에 직접 만들기 시작한 계기는 뭐였나요?

3. [삽질 · 글로 답하기] 영수증 인식 말고, 가계부 앱을 만들면서 가장 오래 헤맨 부분은 어디였나요?

4. [말투 · 고쳐 쓰기] 아래 문장을 계정에 올린다고 생각하고, 내 말투로 다시 써 주세요.  
   예시 문장: 가계부 앱에 기능을 하나 더 넣는 것보다, 하나를 빼는 게 더 어려웠다.

   → (가상 답) 친구들이 먼저 써 보고 안 쓰면 아무리 공들인 기능도 지운다는 거요. 그래서 지운 기능 목록이 만든 기능보다 더 길어요.

## minji · v4

1. [경험 · 글로 답하기] 최근 디자인 과제나 작업을 하면서 가장 기억에 남는 순간 하나를 떠올려 주세요. 어떤 장면이었나요?  
   → (가상 답) 축제 포스터 작업하다가 열두 번째로 시안을 갈아엎던 밤이요. 책상에 버린 스케치가 수북이 쌓였는데, 그걸 보다가 왜 버렸는지 적어 둔 메모에서 오히려 방향이 잡혔어요.
2. [관점 · 둘 중 고르기] 디자인을 공부할 때, 실력이 더 빨리 느는 건 어느 쪽이라고 생각하세요?  
   「레퍼런스 많이 보기」 / 「일단 직접 만들어 보기」 → 일단 직접 만들어 보기  
   → (가상 답) 포스터도 열두 번 넘게 갈아엎으면서 제일 많이 늘었어요. 직접 그려 보고 버려 봐야 왜 안 되는지 알게 돼요.
3. [이유 · 글로 답하기] 디자인 커리어를 준비해야겠다고 처음 마음먹은 순간이 있었나요? 그때 어떤 일이 있었는지 알려 주세요.  
   → (가상 답) 딱 이 순간이라고 하긴 어려운데, 교내 축제 포스터 공모전 때 시안을 열두 번 넘게 갈아엎으면서도 계속 붙잡고 있는 제 모습을 보고 이 일이 나한테 맞나 보다 싶었어요.
4. [고집·취향 · 글로 답하기] 포스터 말고, 디자인 작업할 때 남들은 별로 신경 안 쓰는데 나는 꼭 확인하는 것 하나는 뭔가요?  
   → (가상 답) 버린 시안을 바로 안 지우고, 왜 버렸는지 한 줄 적어 두는 거요. 나중에 보면 그게 다음 작업 고를 때 기준이 되더라고요.
5. [삽질 · 글로 답하기] 포스터 말고, 요즘 공부하는 것 중에 제일 오래 헤매고 있는 건 뭐예요?  
   → (가상 답) 아무래도 툴 다루는 거요. 손 스케치로 잡은 걸 화면에서 그대로 살리는 게 아직 잘 안 돼서, 맨날 거기서 한참 막혀요.
6. [말투 · 고쳐 쓰기] 이 문장을 내 말투로 다시 써 주세요. 인스타 캡션에 올린다고 생각하고, 평소 말하듯이요.
